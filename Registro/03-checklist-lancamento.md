# Checklist de Lançamento de Produto

Use este checklist para cada produto antes de colocá-lo em produção ou venda.

## 1. Identidade do produto

- [ ] Nome comercial definido.
- [ ] Código interno/modelo definido.
- [ ] Revisão de hardware definida.
- [ ] Versão de firmware de produção definida.
- [ ] Número de série e regra de rastreabilidade definidos.

## 2. Engenharia

- [ ] Esquemático revisado.
- [ ] PCB revisada.
- [ ] BOM congelada.
- [ ] Fonte/alimentação validadas.
- [ ] Antenas e interfaces de RF definidas.
- [ ] Gabinete e materiais definidos.
- [ ] Plano de testes de produção definido.
- [ ] Critérios de aprovação/reprovação definidos.

## 3. Firmware e segurança

- [ ] Processo de provisionamento definido.
- [ ] Identidade única do dispositivo definida.
- [ ] Credenciais e segredos protegidos.
- [ ] Atualização de firmware definida.
- [ ] Recuperação após falha de atualização definida.
- [ ] Política de logs e telemetria definida.
- [ ] Política de suporte e ciclo de vida definida.

## 4. Documentação regulatória

- [ ] Dossiê técnico completo.
- [ ] Manual em português concluído.
- [ ] Etiqueta regulatória definida.
- [ ] Fotografias internas/externas arquivadas.
- [ ] Certificados de módulos/componentes arquivados.
- [ ] Enquadramento Anatel confirmado pelo OCD.
- [ ] Ensaios concluídos.
- [ ] Homologação emitida, quando aplicável.
- [ ] Outras certificações obrigatórias avaliadas.

## 5. Marca e comercialização

- [ ] Busca de marca realizada.
- [ ] Pedido de marca protocolado, quando decidido.
- [ ] Domínio reservado.
- [ ] Material comercial revisado.
- [ ] Termos de garantia e suporte definidos.
- [ ] Política de privacidade disponível, quando houver coleta de dados pessoais.

## 6. Plataforma e serviços

- [ ] Dispositivo consegue ser provisionado.
- [ ] Telemetria chega ao backend.
- [ ] Comandos remotos possuem autenticação e autorização.
- [ ] Reprocessamento/reconexão testados.
- [ ] Operação offline/degradada testada.
- [ ] Métricas e alertas definidos.
- [ ] Retenção de dados definida.
- [ ] Integrações externas documentadas.

## 7. Liberação

- [ ] Revisão final de engenharia aprovada.
- [ ] Revisão regulatória aprovada.
- [ ] Revisão de segurança aprovada.
- [ ] Lote piloto aprovado.
- [ ] Produto autorizado para produção/comercialização.

## Registro da aprovação

Para cada produto, manter um documento de liberação contendo:

- produto/modelo;
- revisão de hardware;
- versão de firmware;
- lote inicial;
- data da aprovação;
- responsáveis pela revisão;
- certificados aplicáveis;
- pendências aceitas e justificativas.
